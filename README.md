# rectpack

---

This is a port of TeamHypersomia's [rectpack2D](https://github.com/TeamHypersomnia/rectpack2D) to C#/.NET.


## credits

Directly ported and adapted from [`TeamHypersomia/rectpack2D`](https://github.com/TeamHypersomnia/rectpack2D).

Naive tests adapted from [`ThomasMiz/RectpackSharp`](https://github.com/ThomasMiz/RectpackSharp) (another rectangle packing library for .NET that's based more loosely on rectpack2D).
